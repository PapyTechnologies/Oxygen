# Changelog

All notable changes to Oxygen Browser are documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-15

### Added
- Multi-tab web browser powered by Tauri 2 and WebView2 Evergreen architecture.
- Built-in network ad-blocking engine with zero-overhead DNS and URL pattern filtration.
- Integrated AI assistant panel with provider support (Anthropic, OpenAI, Google Gemini, DeepSeek, OpenRouter, GitHub Models).
- Windows Credential Manager integration for secure API key storage.
- Live streaming and video capture supervisor using FFmpeg with hardware-accelerated encoding options.
- WASAPI automatic loopback audio capture supporting full system audio playback.
- Dynamic tab memory optimizer and active RAM tree reporting.

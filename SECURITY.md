# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security and privacy of Oxygen Browser very seriously.
If you discover a security vulnerability or credential handling concern, please report it privately:

- **GitHub Private Vulnerability Reporting**: Open an advisory via the **Security** tab of this repository.
- Please include reproduction steps, expected vs. observed behavior, and system environment details.
- Please do not submit vulnerability reports via public issue trackers.

Reports will be acknowledged within 48 hours, followed by a remediation and security release plan.

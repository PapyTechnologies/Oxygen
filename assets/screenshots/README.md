# Oxygen Screenshots Guide

Place the following clean 1080p (or 720p) screenshots in this directory for documentation and showcase:

| Filename | Content & Description | Sensitivity Rule |
| :--- | :--- | :--- |
| `01_navigation_overview.png` | Main browser window, clean tabs bar, dark theme homepage. | No private URLs or bookmarks. |
| `02_adblock_protection.png` | Shield badge open showing blocked ads and trackers counter. | Clean public news site test. |
| `03_ai_assistant.png` | AI assistant sidebar chatting or summarizing a page. | No API keys visible. |
| `04_live_streaming_panel.png` | Streaming settings modal (DDA screen capture, WASAPI audio). | No RTMP stream keys visible. |
| `05_downloads_manager.png` | Fast download panel showing finished or ongoing downloads. | No personal directory paths. |
